## 0. 一句话摘要（上板前先看这三条）

1. **先验魔数**：`pid=` 必须等于 `0x4D4D5450`（或 `link=` 的 `[31:17] == 0x2A5C`）。
   读不到 ⇒ **位流没重编**（本次改了 RTL/SW，**必须重编**，见 §6）。
2. **`[CAM]` 的字段名现在与寄存器一一对应**（§7 修掉了错位）。判读顺序见 §4；判读坑见 §2。
3. **`0xC0/0xC4` 不再映射**（读到 0）；探针窗口是**连续**的 `0x80..0xBC`（raddr 0..15）。

## 2. 判读坑清单（每条给"用哪个字段判"）

### 2.1 `PCLK` 永远在涨，**与摄像头无关** ⇒ 用 `CK/PCLK` **增量比**

- `i_mipi_rx_pclk` 是 **PLL 输出**（`mmt.peri.xml:391`，out_divider=56）⇒ PLL 一锁它就跑，
  摄像头接没接都涨 ⇒ **`PCLK` 非 0 什么都不说明**（只证明 PLL/探针活着）。
- **正确用法**：读两次 `CK=`/`PCLK=`，算 **`ΔCK / ΔPCLK`**（两边都 ÷1024，比值就是频率比）。
  - `ΔCK = 0` 而 `ΔPCLK > 0` ⇒ **字节时钟没来** ★ 关键；
  - 两者都涨、比值稳定 ⇒ MIPI 时钟链在跑（**仍不代表数据在传**，§2.6）。
- **更直接的一手证据**：`rh=`（= `RST_HS_STAT`）的 `[2]`（`ck_HS_ENA`）与 `[7]`（曾拉起）——优先看它。
- **【无法确认】** `ΔCK/ΔPCLK` 的**期望值**（取决于 lane 数与像素格式）⇒ **别跟常数比**。

### 2.2 `SCL(d=0)` **不等于**故障 ⇒ 看**总数**与"是否已停止增长"

- 配置序列开机发一次，**发完 SCL 就不动** ⇒ 稳态 `d=0` 正常；只有 **总数 = 0** 才是"没跑"。
- **总数期望量级【推断】**：`i2c_master_reg_set.v:4` 的 `DATA_LENGTH = 61`（61 条），
  每条写事务约 4 字节 × 9 拍 × 2 跳变 ⇒ **量级 2×10³ ~ 4×10³**。
  **精确值无法确认** ⇒ **不要跟常数比**，判据是"非 0 且已停止增长"。
- `st=` 的 `[6]`(`scl_seen`) 是"曾经动过"的最省事判据；`[0]` 只是**当前**电平。

### 2.3 `wc(d=0)` **不等于**故障 —— `wc` 数的是**值变化次数**，不是包数

- 【实测：`mmt_cam_probe.v:244-252`】`wc_tg` 在 `csi_word_count != wc_d` 时翻转 ⇒ `wc` = 值变化次数。
  同帧内各行包的 `word_count` 常相同 ⇒ **稳态每帧只变几次，`d=0` 正常**。
- **"包在不在动"用 `HS=`/`VS=`**；**"包多大"用 `wmx=`(WC_MAX) 与 `wc` 快照（0xA4，当前未打印）**。

### 2.4 `fifo_rd_empty` **不能当证据**

- 【实测：`mmt_cam_probe.v:385`】逐位 2FF 的**瞬时快照**（`link` 的 `[7:4]`）⇒ 读到什么都不能下结论。

### 2.5 `d=` 没有固定时间基准 ⇒ 只能比零/非零与数量级

- 打印是"软件空循环 `for (volatile int i=0;i<2000000;i++){}` + 串口打印"（`sw\main.c:566`），
  且注释说"跟着 MLX90640 的 2Hz 走" ⇒ **间隔不可知且不保证**。
- ⇒ 只能问"**涨没涨 / 增量是不是 0 / 量级对不对**"，**不能**用"增量 ÷ 间隔"换算频率。

### 2.6 `CK` 在涨 **只说明 HS 时钟 lane 有时钟**，不说明数据 lane 有数据

- 数据 lane 全 0 也会看到同样的 `CK`。
- ⇒ "数据 lane 有没有进 HS"看 **`rh=` 的 `[6:3]`/`[11:8]`**；
  "数据是不是全 0"看 **`st=` 的 `[14]`(`pd_any`)** 或 **`pd=`（0xAC，本轮修正后可读）**。

### 2.7 探针"在不在位流里"要看魔数（两处都行）

- `pid== 0x4D4D5450`（`0xA8`，本轮修正后可读）**或** `((link >> 17) & 0x7FFF) == 0x2A5C`。
- 两处都读不到 ⇒ **位流没重编**（先别往下判）。
- ⚠️ **修复前** `pid=` 读到的是 `WC_MAX`（§7）⇒ 会误判"没重编"；现在不会了。

### 2.8 `SCL` 探针接的是 **OE**，不是 SCL 输出

- `cam_scl` 现在接 `io_cam_scl_OE`（`mmt_top.v:679`，`= ~scl_padoen_o`）；真正的 `scl_o` 在
  OpenCores I2C 里**恒为 0**（`i2c_master_ctrl_top.v:13` 注释即写 "always 1'b0"）。
- ⇒ `st=` 的 `[0] = 1` 表示 **SCL 正被拉低**。读反会得到相反结论。

### 2.9 地址别名的自检（**修复后应消失**，§7）

- **修复前**：`nk` 恒等于 `SCL`、`rh` 恒等于 `CK`（因为 0xC0/0xC4 被截断成 raddr 0/1）。
- **修复后**：`nk` = `I2C_NACK_CNT`（0xB8）、`rh` = `RST_HS_STAT`（0xBC），**与 SCL/CK 无关**
  ⇒ 若你在新位流上**仍然**看到 `nk == SCL` 且 `rh == CK`，说明**位流没重编**（或 RTL 没更新）。

|---|---|---|---|---|---|
| 0 | **位流里没有探针** | `pid=` 或 `link[31:17]` | `0x4D4D5450` / `0x2A5C` | 读不到 ⇒ **位流没重编**，下面全不要信 | 顺带自检 `nk≠SCL`、`rh≠CK`（§2.9） |

### 3.1 有歧义、必须联合看

| 组合 | 两种解释 | 怎么区分 |
|---|---|---|
| `SCL` 非 0 但 `ACK=0` | (a) 传感器不应答；(b) ACK 监视器没抓到 | 看 NACK：`NACK>0` ⇒ (a)；`ACK=NACK=0` 而 SCL 非 0 ⇒ 多半 (b)（位计数被 START/STOP 复位逻辑清掉）⇒ **需上板实测确认** |
| `[7]=1`（ck 曾 HS）但 `[11:8]=0` | (a) 数据 lane 没进 HS；(b) 进了但 IP 没报 | 看 `CK` 是否在涨 + `wmx=` 是否为 0：CK 涨而包计数全 0 ⇒ 倾向 (a) |
| `de_seen=1` 但 `DE` 增量小/为 0 | (a) DE 只跳了一两次；(b) 已被后级吞掉 | 看 `HS`/`VS` 与 `st` 的 `[3]`（DE 当前电平） |
| `pd`/`pd_any` 为 0 | (a) 像素真的全 0；(b) `csi_pixel_data` 接错/没接 | 看 `[11:8]` 是否拉起 + `link` 的 dt/ppc：d0..d3 从未 HS ⇒ 多半根本没数据 |

## 4. 上板操作顺序（照这个顺序，别跳步）

> 每步**读两次**（相邻两行 `[CAM]`），只看**增量**与**粘滞位**。

| 步 | 目的 | 看 | 判据 / 分支 |
|---|---|---|---|
| **1** | **确认位流里有探针** | `pid=`（或 `link` 高 15 位）+ `nk≠SCL`、`rh≠CK` | `pid==0x4D4D5450` ⇒ 继续；否则**停**，位流没重编（§2.9） |
| **2** | PLL / 复位 | `rh=` 的 `[0]`/`[1]` | `1`/`1` ⇒ 继续；`[0]=1 & [1]=0` ⇒ **像素时钟没跑**，查 MIPI PLL/参考时钟 |
| **3** | I2C 有没有跑 | `SCL=` 两次 + `st=`[6] | 总数非 0 ⇒ 跑过；**仍在涨** ⇒ 没发完/反复重发；0 ⇒ 查 `CLK_5M`/I2C 启动 |
| **4** | **传感器有没有应答** ★ | `ack=`、`nk=` | `ACK>0 & NACK≈0` ⇒ 传感器在；`ACK=0 & NACK>0` ⇒ 接线/地址/上电；都 0 ⇒ §3.1 |
| **5** | **MIPI HS 握手** ★★ | `rh=` 的 `[2]`、`[7]`、`[6:3]`、`[11:8]` | ck+d0..d3 都曾起 ⇒ PHY 收进 HS；**ck 起而 d* 没起 ⇒ 最可疑（排线/端接）** |
| **6** | CSI 解出了什么 | `link`(ppc/dt/vc)、`wc`、`wmx=` | `dt` 非 0 + `wmx` 非 0 ⇒ 正在解包；否则回第 5 步 |
| **7** | 数据有效性 | `pd=`、`st=` 的 `[14]`(`pd_any`)、`[7]`(`de_seen`) | `de_seen=1` 且有非 0 ⇒ 有真数据；都为 0 ⇒ **DE 在跳但像素全 0** |
| **8** | 出图有没有到帧缓冲 | `DE=`/`VS=` + 帧缓冲寄存器（`0xD8/0xDC`） | DE/VS 涨而帧缓冲不写 ⇒ **转写通路排查** |
| 附 | 时钟链辅助 | `CK=`/`PCLK=` 增量比 | `ΔCK=0` 而 `ΔPCLK>0` ⇒ 字节时钟没来；**不要**用 `PCLK` 非 0 当好消息 |

## 7. ★ 本轮修掉的地址错位缺陷（记录）

### 7.1 现象（**【实测】** 上板/读码会看到什么）

`[CAM]` 行的 6 个字段读到的**不是**名字对应的寄存器：

| 字段 | 修复前**实际**读到 | 危害 |
|---|---|---|
| `pid=` | `CSI_WC_MAX` | 魔数校验必然失败 ⇒ **误判"位流没重编"** |
| `pd=` | `I2C_ACK_CNT` | 把 ACK 数当"数据有效拍数" |
| `ack=` | `RST_HS_STAT` | 正常即 `0x00000003` ⇒ **伪装成"3 次 ACK"**（最危险） |
| `nk=` | `CAM_SCL_CNT`（**别名**） | **恒等于 `SCL=`** |
| `wmx=` | `I2C_NACK_CNT` | 把 NACK 当最大词数 |
| `rh=` | `CAM_CK_CNT`（**别名**） | **恒等于 `CK=`** |

### 7.2 根因（**【实测】** 代码依据）

探针译码是**线性连续**的：`cam_probe_raddr = PADDR[7:2] − 32`，且该信号只有 **4 位**（`mmt_soc_regs.v:186`）。
而 ① `FB_AWADDR_MAX`/`FB_AW_STAT` 的**显式 `case` 插在 0xA8/0xAC**（`:380`/`:383`），
显式 case **优先于** `default`（`:401` 才走探针）⇒ 探针 `raddr` 10/11 永远读不到；
② 上界原写 `<= 49`（0xC4）⇒ 0xC0/0xC4 算出 `raddr` 16/17，被 4 位宽**截成 0/1** ⇒ **别名**。

### 7.3 修法（**已实施**）

| 改动 | 文件 |
|---|---|
| fb 两个寄存器 `0xA8/0xAC` → **`0xD8/0xDC`**（空闲，已核对与 23 个既有地址、0xC8..0xD4、探针窗口都不冲突） | `rtl\mmt\soc\mmt_soc_regs.v:378-386` |
| `probe_sel` 上界 `49` → **`47`（0xBC）** ⇒ 窗口变成连续无洞的 0x80..0xBC，0xC0/0xC4 返回 0 | `rtl\mmt\soc\mmt_soc_regs.v:333-347` |
| 6 个探针宏地址改正 + fb 两个宏改 0xD8/0xDC | `sw\mmt_regs.h:90-148` |
| B 组边界用例 + C 组标签 | `sw\test\tb_mmt_cam_probe.v` |
| 20 处 `0xA8/0xAC` → `0xD8/0xDC`（同轮跑通 45/0） | `sw\test\tb_mmt_soc_regs.v` |
| 表头注释同步 | `mmt_soc_regs.v` 头部、`mmt_regs.h`、`main.c`、两个 TB |

### 7.4 修复前 / 后 字段对照表（上板自检用）

| `[CAM]` 字段 | 修复前实际寄存器 | **修复后实际寄存器** | 自检 |
|---|---|---|---|
| `pid=` | `CSI_WC_MAX` | **`PROBE_ID`（0xA8）** | 必须 `0x4D4D5450` |
| `pd=` | `I2C_ACK_CNT` | **`CSI_PD_CNT`（0xAC）** | `de` 在跳时应 > 0 |
| `ack=` | `RST_HS_STAT` | **`I2C_ACK_CNT`（0xB4）** | 传感器应答时应 > 0 |
| `nk=` | `CAM_SCL_CNT`（别名） | **`I2C_NACK_CNT`（0xB8）** | **不应再恒等于 `SCL`** |
| `wmx=` | `I2C_NACK_CNT` | **`CSI_WC_MAX`（0xB0）** | 包最大词数 |
| `rh=` | `CAM_CK_CNT`（别名） | **`RST_HS_STAT`（0xBC）** | **不应再恒等于 `CK`** |
| `SCL/CK/PCLK/DE/HS/VS/st/wc/link` | 正确 | 正确（不变） | — |

**⇒ 上板第一眼的判据**：`pid == 0x4D4D5450`、且 `nk != SCL`、`rh != CK`。
三条同时成立才说明**新位流 + 新软件**都生效了；否则先别信任何字段。

## 附：一句话 SOP

**`pid`/`link` 验魔数（并确认 `nk≠SCL`、`rh≠CK`）→ `rh[1:0]` 验 PLL/复位 → `SCL` 验 I2C 跑没跑 →
`ack`/`nk` 验传感器应答 → `rh[11:2]` 验 MIPI HS 握手 → `link`+`wc`+`wmx` 验 CSI 解出什么 →
`pd`/`st[14]` 验数据非全 0 → `DE`/`VS` 验 DE/VS → 最后才轮到帧缓冲写通路。**
