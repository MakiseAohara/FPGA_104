## 1. 关键前置条件（缺一个都跑不起来）

### 1.1 ⚠️ FTDI 驱动版本必须"统一"——否则会蓝屏
本机事故（2026-10-12 23:06 与 23:14）：**两次 BSOD `0x000000FC`（ATTEMPTED_EXECUTE_OF_NOEXECUTE_MEMORY）**，时间与"访问板载 FT4232H"严格对应。

**根因（已证实）**：板载 FT4232H 有"总线"与"串口"两条通道，而 Windows 里被装成了**两个不同年代**的驱动：
- `ftdibus.inf` 2024 版 `2.12.36.20`
- `ftdiport.inf` 只有 2017 版 `2.12.28`

**修法（实测有效）**：删掉全部旧包，只装 FTDI 官网 CDM 包（`ftdibus.inf` + `ftdiport.inf` **同版本**）：
```
pnputil /delete-driver oem114.inf /uninstall
pnputil /delete-driver oem118.inf /uninstall
pnputil /delete-driver oem119.inf /uninstall
pnputil /add-driver D:\FTDI\ftdibus.inf  /install      # CDM-v2.12.36.4-WHQL-Certified
pnputil /add-driver D:\FTDI\ftdiport.inf /install
```
修完后**四个通道版本一致**（实测）：
- `USB Serial Converter A/B/C/D` → `oem96.inf` **2.12.36.4**
- `USB Serial Port COM17~20` → `oem114.inf` **2.12.36.4**

> 参考（同类问题）：<https://bigpig.ongridea.com/gha5jb> ——"FT4232H 的 JTAG 与串口两个通道被装成不同版本驱动打架"。

### 1.2 必须打开 `EFX_HIFTDI_ENABLE=1`
Efinity 默认只用 **pyftdi(libusb)** 后端，而板载 FT4232H 挂在 FTDI 驱动上 → 报 `No backend available`、`usb_target_list = []`、`No Board Profile Selected`。
**D2XX 后端藏在开关后面**（源码依据 `pgm\bin\efx_pgm\usb_resolver.py:712`）：
```powershell
$env:EFX_HIFTDI_ENABLE = "1"
```
打开后即可枚举到：
```
Available USB targets:
Usb Target: Quad RS232-HS, ID: 0403:6011
	url[0]: hiftdi://0x0403:0x6011/0
	url[1]: hiftdi://0x0403:0x6011/1     ← JTAG（profile 里 TCK/TDI/TDO/TMS = BDBUS0..3）
	url[2]: hiftdi://0x0403:0x6011/2
```

### 1.3 必须打一个补丁：`efx_dbg\jcf.py`（Efinity 自身 bug）
**症状**：D2XX 后端下**任何**模式（含只读 `read_flash`）都在 TAP 检测处抛：
```
TypeError: JtagEngine.configure() takes 2 positional arguments but 3 were given
  at efx_dbg\jcf.py:795 → self._engine_provider.configure(url, init)
```
**原因**：hiftdi 的底层 JTAG 引擎 `configure()` 只接受 `(url)`，而调用方无条件多传了 `init`（pyftdi 引擎才接受 `init`）。

**补丁**（`D:\Efinity\2026.1\debugger\bin\efx_dbg\jcf.py`，两处 `else:` 分支；原文件备份在 `工程\jcf.py.bak`）：
```python
        else:
            try:
                _np = len(__import__('inspect').signature(
                    self._engine_provider.configure).parameters)
            except Exception:
                _np = 2
            if _np >= 2:
                self._engine_provider.configure(url, init)
            else:
                self._engine_provider.configure(url)
```
打完后语法自检：`python -m py_compile jcf.py` → 退出码 0。

### 1.4 必须指定板级 profile
`-b "Generic Board Profile Using FT4232H"`（`pgm\bin\efx_pgm\efx_hw_common\boards\generic_ft4232h.json`；VID 0x0403 / PID 0x6011 对得上）。

## 2. 实测可用的完整命令

### 2.1 生成位流（`.hex` + `.bit` 一次出）
```powershell
& "$efi\bin\efx_pgm.exe" --project-xml D:\FPGA\mmt\mmt.xml `
  --source D:\FPGA\mmt\work_pnr\mmt.lbf --dest D:\FPGA\mmt\out\mmt.hex `
  --family Titanium --device Ti60F225 --mode active --width 1
```
实测：`out\mmt.hex`（文本，约 2.8 MB；**真实数据约 955 KB**）+ `out\mmt.bit`。

### 2.2 JTAG 烧 SRAM（**已实测通过**）
```powershell
$env:EFX_HIFTDI_ENABLE = "1"
& "$efi\bin\python3.bat" "$efi\pgm\bin\efx_pgm\ftdi_program.py" `
  "D:\FPGA\mmt\out\mmt.bit" -m jtag -b "Generic Board Profile Using FT4232H"
```
**成功输出（判据）**：
```
Connecting to JTAG_TAP: efx_ti
jtag programming started!
Programming 'D:\FPGA\mmt\out\mmt.bit' via JTAG at freq 6.0 MHz
Device ID read from JTAG: 0x10660A79
... finished with JTAG programming
```
> ⚠️ JTAG 模式**必须用 `.bit`**；传 `.hex` 会报 `Incompatible file extension ... please use .bit file for JTAG`。

### 2.3 串口（**设计活着的最直接证据**）
- **端口：`COM19`**（115200 8N1；实测 `COM17/18/20` 无数据）
- 预期：持续输出 `T=..C RH=..% IR=..C score=..`
- 用 PowerShell 快速验证：
```powershell
$sp = New-Object System.IO.Ports.SerialPort 'COM19',115200,'None',8,'One'
$sp.Open(); Start-Sleep 3; $sp.ReadExisting(); $sp.Close()
```

### 2.4 只读备份板载 flash（已做过）
```powershell
... ftdi_program.py -m read_flash -o 工程\板载flash备份_出厂.bin --address 0 --num_bytes 8388608 -b "Generic Board Profile Using FT4232H"
```
实测：`Reading 8192 KiB ... Finished read in 12 seconds`（输出为文本格式，24 MB）。
⚠️ 但 JEDEC ID 读回是 `0x822699`（GD25LQ64 应为 `0xC8 0x40 0x17`）⇒ **这份备份的可靠性存疑**，见 §5。

## 5. 尚未打通：flash 持久化烧录

| 方式 | 结果 | 原因 |
|---|---|---|
| `-m jtag`（SRAM） | ✅ 通 | JTAG 直配 |
| `-m active`（直连 SPI 通道 A） | ❌ `Unknown error trying to read flash device` | 板子的 flash **不直连** FT4232 通道 A（该 profile 的 SPI 引脚映射对不上），JEDEC 读不出 |
| `-m jtag_bridge`（厂商默认的 flash 编程方式） | ❌ `NotImplementedError: ERROR, Not Implemented Yet`（`efx_hw_common\manager.py:269`） | **hiftdi(D2XX) 后端未实现** JTAG Bridge |

**下一步方案**：用 **Zadig** 把 FT4232H 的 **JTAG 接口（通道 B / interface 1）** 绑成 **libusbK/WinUSB**，改用 Efinity 默认的 **pyftdi(libusb)** 后端（此时**不要**设 `EFX_HIFTDI_ENABLE`），再试 `-m active` / `-m jtag_bridge`。
- 这是厂商文档（《炫览下载器说明及驱动安装》方法一）描述的官方路径
- ⚠️ 属于**换驱动**操作：动手前建系统还原点、板子先拔掉，并由人守着

**在此之前**，上板验证走 §2.2 的 SRAM 烧录即可（每次上电后烧一次，约 20 秒）。
