# 视频分镜脚本（只拍视频、不现场演示）

> 建议总时长：**6.5–7.5 分钟**（下限 5 分钟、上限 8 分钟）。
> 原则：**所有"运行画面"必须是真实设备实时运行录制**；框图、表格、日志截图属于说明性素材，需在画面中标注"说明性素材/日志截图"，不得与实拍混淆，更不得合成或伪造运行画面。
> 录制前必须核对：位流 = MERGE11（SHA256 `ECE19288…4C15`）、固件 = `tinyml_pdti8_merge11.bin`（或 v16 变体），OSD/串口日志正常。

## 2. 拍摄前检查清单

**设备与版本**
- [ ] 位流：MERGE11（`project/v7_camera_ai/bitstream/v7_MERGE11.bit`，SHA256 `ECE19288C8C34C64B29554310287ABC810FC2FB6388350D998DA5C47DAA14C15`）。
- [ ] 固件：`tinyml_pdti8_merge11.bin`（v15，②⑤做演示）或 v16 变体（预处理对比）；先起加载器再烧位流。
- [ ] 蜂鸣器是否已接（未接则旁白说明，不拍"响"的画面）。
- [ ] 串口终端 115200 8N1，日志从 `MMT_BOOT` 开始完整录制。

**场景**
- [ ] 光线稳定（避免逆光/频闪/强光直射镜头）；需要时固定曝光。
- [ ] 站位：人距摄像头 1.5–2 m、全身或半身入镜；背景干净、无强热源（暖气/热饮/阳光）。
- [ ] 夜间窗口：确认按键切到夜间（OSD 显示 `NIGHT`），否则不会报"入侵"。
- [ ] 传感器接线：SCL=J7-32（GPIOL_11）、SDA=J7-34（GPIOL_09）、3.3 V/GND；上拉电阻确认。
- [ ] HDMI 显示器支持 1080p60；采集卡/录屏软件就绪（分辨率、帧率与实际一致）。

**OSD 显示项（画面核对）**
- [ ] 第 0 行：`T=xx.xC RH=xx.x% HR=xx NIGHT`
- [ ] 第 1 行：`IR=xx.xC MOTION=x AREA=xxxx`
- [ ] 第 2 行：`EVT=... CONF=xx.x SNS=OK`
- [ ] 热力图小窗有内容；报警时整屏红框。

**录制**
- [ ] 主机时间戳与串口日志同步（方便与画面事件对齐）。
- [ ] 每个镜头至少录 2 遍，保留原始文件（不做删改）。
- [ ] 画面中不出现学校名称、人名、队名、账号等敏感信息。

## 4. 失败预案（不允许合成或伪造画面）

| 问题 | 处理方式（如实） |
|---|---|
| 摄像头不出图 | 检查 FPC 与位流；若现场无法修复，**使用历史真实录屏**并在画面显著标注"历史位流实测（日期/配置）"，不冒充当前运行 |
| ②/⑤ 板上未见效 | 改为展示**仿真/构建日志截图**，旁白明确"已完成仿真与构建验证，板上验证见待补"，**不得**把仿真波形/日志剪成实拍画面 |
| MLX 无读数 | 展示真实 I2C 诊断日志（SCL/SDA 计数、地址扫描 P=/A=/B=）与 OSD `SNS=ER`，说明当前实现范围与待补项 |
| 报警不触发 | 检查夜间窗口/红外热点/背景学习；如实录制排查过程与最终状态，不伪造报警 |
| 蜂鸣器未接 | 用 LED + OSD 红框 + `EVT=INTRUDE` 演示，旁白说明"蜂鸣器模块可外接" |
| 画面明显偏暗/偏亮 | 优先固定曝光；若使用 v16 自动曝光固件，展示 `MMT_AE` 真实日志，不口述"已自动调节" |
| 低功耗 15 s 不进入 | 确认无人且无红外热点（热源会阻止进入）；如实展示 `MMT_LP` 未进入的原因（低功耗状态 bit17=0） |
