## 3.1 整体介绍

**一句话**：一块 Ti60F225（Titanium）开发板，外接 SC431HAI 摄像头 + SHT30 温湿度 + MLX90640 红外阵列，
在 FPGA 内完成"采集 → DDR 帧缓冲 → 1080p HDMI 显示 + OSD"，同时用 Sapphire RISC-V 软核跑
TinyML 人体检测、多目标跟踪、行为预测、低功耗管理和报警决策，并把状态通过串口/千兆网口送出。

系统框图（文字版，画图时按这个）：

```
SC431HAI ──MIPI CSI-2──► 去马赛克 ──► DDR3 帧缓冲 ──► 缩放/OSD ──► HDMI 1080p
                              │
                              ├──► 96×96 灰度（AI 输入）──► TinyML 人体检测 ─┐
SHT30 / MLX90640 ──I2C──► 温湿度/热成像 ───────────────────────────────────┤
                                                                          ▼
                                                    Sapphire RISC-V 软核（决策/跟踪/预测/低功耗）
                                                      │            │
                                                   UART 状态     千兆网口(RGMII) → PC
```

**【需补图】3.1 整体照片**：整机正面 + 斜 45° 全局照（含摄像头、开发板、HDMI、网线、串口线）。
拍摄要点：光足、不逆光、HDMI 上要有画面（最好正好是"画面里 1 人"的状态）。

## 3.2 工程成果

### 3.2.1 机械成果
- 本项目无自研机械结构，使用厂商 Demo 板 + 摄像头支架（3D 打印/现成支架）。
- **【需补图】** 摄像头安装方式特写 1 张（说明视场高度、俯角），便于复现。

### 3.2.2 电路成果
- 主控：Elitestek Ti60F225I3-V4（Titanium Ti60F225，60800 XLR / 256 BRAM / 160 DSP）。
- 传感器：SC431HAI（MIPI CSI-2）；SHT30（I2C，0x44）；MLX90640（I2C，0x33）。
- 网络：板载 YT8531SH 千兆 PHY，RGMII 14 根信号 + MDIO/MDC。
- 电源/时钟：25 MHz（DDR3 PLL）、27 MHz（视频 PLL），DDR3 由 PLL_TR0 驱动。
- **【需补图】** 开发板高清特写（正上方，能看清芯片丝印、摄像头排线、网口）。

### 3.2.3 软件成果
- **FPGA RTL**：视频链路（去马赛克/DDR3/缩放/OSD）、I2C 分时复用、运动检测、帧差法、
  红外热区、APB 寄存器组、千兆网口收发（`rtl/ge/`）。
- **RISC-V 固件**（`evidence/v30_mot/main_live30.cc`）：TinyML 推理、IOU 多目标跟踪、
  行为预测、低功耗状态机、报警融合决策、串口协议、网口收发与 HTTP（开发中）。
- **PC 端工具**（`tools/`）：实时监控网页（`web_monitor.py` + `page.html`）、
  固件打包/烧录（`load_retry.py`）、离线回放与数据分析脚本。
- **【需补图】界面照片**：
  1) 浏览器监控页整页截图（大字状态 + 画面 + 人数面板 + 技术细节展开）；

## 3.3 特性成果（逐项 + 量化指标）

| # | 功能 | 实现方式 | 实测指标 |
|---|---|---|---|
| 1 | 1080p 视频显示 | SC431HAI → MIPI → DDR3 → HDMI | **60 fps**，HDMI 1080p |
| 2 | 红外热成像 | MLX90640 I2C 读取 + 伪彩叠加 | 刷新率随 I2C 分时复用（约 4 帧/秒） |
| 3 | 温湿度 | SHT30 I2C | 温度 0.1 ℃、湿度 0.1 %RH 分辨率 |
| 4 | AI 人体检测 | TinyML int8 96×96，软核推理 | **约 1 Hz**，与运动/红外融合判定 |
| 5 | 多目标跟踪 | 背景差分 + 连通域 + IOU 关联 | 目标上限 **2**，稳定 ID，实测 1 人不再误报 2 个 |
| 6 | 行为预测 | 速度向量一阶 EMA + 前视外推 | 2 帧外推中位误差 5.66 px（不动 3.16 px，见备注） |
| 7 | 低功耗管理 | 30 s 无活动暂停推理、保留温度采集 | 进入 30 s，人出现后 ≤1 s 恢复 |
| 8 | 报警 | 运动面积 + 红外热计数 + AI 佐证，红框同步 | 报警延迟约 2 s（固件可调） |
| 9 | 千兆网口 | RGMII + 自研收发 + 软件组帧 | 链路 1 Gbps，UDP 64 B×1418 帧 0 错误 |
| 10 | 远程监控 | PC 端 HTTP（板内 HTTP 开发中） | 页面 4 KB，刷新 0.4 s |

**备注（如实写）**：行为预测的 2 帧外推在当前帧率下误差大于"假设人不动"，
说明预测链路可用但参数需要按帧率重标定（`evidence/session_1102/verify_prediction2.py`）。

b) PC 上收包脚本输出（网口上报）。
