## 评审时采用的口径

- **人数、ID、速度与落点均为算法估计。** 合成场景有完整位置真值；历史实拍没有人工人体框/身份真值，不能把输出覆盖率称为真人召回率。
- **实时网页是降采样监控。** 最终观测为 PC 2.20 FPS、板页 2.00 FPS，受输入场景与功耗状态影响；不承诺各场景恒定达到该数值。
- **功能记录不替代工程签核。** 当前位流 setup 余量为 −1.103 ns，尚未完成时序闭合；本机 Efinity 为 2026.1.132，不能声称已在 2025.1 重新构建验证。
- **交付方式是临时加载。** JTAG 位流加 UART RAM 应用，未写 SPI Flash，断电需要重新加载。旧版本证据与回退包保留，但应同时核对应用、位流和网页版本。

下一步应补齐连续真人视频及人工标注、现场双人交会/遮挡验收、红外校准与低功耗降帧/功耗测量，再给出对应条目的完整通过结论。原始记录从[证据索引](EVIDENCE.md)进入。
