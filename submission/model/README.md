# model — v29 人体检测模型

- 结构：5 层卷积（3×3 s2，通道 16/32/48/64/80）+ GAP + FC32 + FC2，**95,922 参数**，INT8，96×96×1 输入。
- 量化：输入 `scale=1/127.5, zp=-1`（像素 u−128），输出 `1/256, zp=-128`；模型 101,088 B。
- 指标：COCO 验证 70.0%（AUC 0.775，n=3000）；场景 F 段 98.1%（AUC 0.986，n=54）；白天段 94.6%（AUC 0.997，n=56）；单次推理 226 ms/invoke。
- 目录 `v29_model/`：`README.md`（评估表）、`v29_person_96_int8.tflite`、`generator/`（官方 Generator 产物）、`_round1/`、`_bad_export/`（历史）、训练/量化/评估脚本。
