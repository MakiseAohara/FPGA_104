## 当前增益的记录边界

源码内 VIO 初始 R/G/B 值为 `0x118 / 0x0E8 / 0x158`，gamma_sel 初始为 0。这里记录的是位流源代码的初始化值，不是成功回读的当前硬件输出值。现有 VIO API 的输出属性为主机缓存，未将它用作硬件读回证明。

首次厂商控制器初始化包含调试核软复位；恢复后的三个只读探针绕过了控制器初始化，没有再次发送该软复位。三个探针都没有编程、相机写入或 RGB 增益写入路径。
