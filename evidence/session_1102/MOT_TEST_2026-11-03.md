# 多目标实测分析（2026-11-03 傍晚，200 s 实拍）

## 结论先行

**这次测试不能用来判断多目标好坏**：整段里 MOT 的检测框**中位数就是 96×96（整幅）**，
P90 也是 96×96。也就是说镜头里看到的几乎全是"整幅前景"，跟踪器面对的是一个
占满全画面的巨大连通域——两个人是否分开、ID 是否稳定都无从谈起。

## 数据

| 指标 | 值 |
|---|---|
| 采样 | 200 s，184 次 MOT 调用，332 条航迹行 |
| 检测框尺寸 | 宽/高 中位 **96×96**，P90 96×96 |
| 宽高比 >2.2 的框（疑似两人并列） | 3 / 332 = **1%** |
| ID 总数 | 18 |
| ID 存活时间中位 | **2.4 s**（只有 ID 40 活了 69 s） |
| 每 10 s 的 nt | 绝大多数是 1；偶尔 2（0 s、40 s、90 s、170 s 附近） |

## 为什么会出现整幅框

三种可能，按概率：
1. **人离镜头太近**（1 m 内），前景连成一片，膨胀后铺满 96×96；
2. 自动曝光/补光变化导致整幅灰度跳变，被判成前景（这种情况固件里有 big_reset 兜底，
   但只有 AI 判无人且红外不热时才触发）；
3. 背景模型被污染（长期有人站在画面里，背景被"吃掉"）。

## 对跟踪器的直接影响

- 整幅框在 `mot_update_track` 里会被清零速度（有专门判断），但**仍然会建航迹**；
- 于是任何一次光照跳变都会新建/丢弃一条 ID → 这就是 ID 存活中位只有 2.4 s 的原因；
- 两个人都在画面里时，前景连成一片 → 只有一个连通域 → **并成 1 个目标**（数据里 nt=1 占多数）。

## 要拿到有效数据，重测条件

- 人站 **2–3 m**，让检测框落在 ~20–40 px（宽高比接近 1:2~1:3 的人形）；
- 画面里不要有强逆光/补光灯直射；
- 空场先等 10 s 让背景模型稳定，再进人。

## 代码侧可以立刻改的两处（等数据确认后再定）

1. **整幅框不建航迹**：`mot_add_det` 里对 `w>=0.9*MOT_W && h>=0.9*MOT_H && ai_p<0` 的检测直接丢弃
   （我试过这版，在现有录制上无变化，需要真实数据验证）；
2. **ID 保活**：确认过的航迹在 `miss` 期间若 AI 仍判有人，把 `MOT_MAX_MISS` 从 6 放宽到 ~10，
   减少"人还在但 ID 换了"的情况。
