## 像素换算（2026-10-27 修正）

串口 MMT_IMG 的字节是 **int8 的二进制补码**（MMT_IMGSTAT 打印 min=-128 max=127 mean=32，
按 int8 解读原始字节得到的 stats 与之逐项吻合）。因此正确换算为：

`
u = int8(byte) + 128        # 0..255，模 256 回绕，不截断
`

早期版本写成 clip(byte + 128, 0, 255)，把 yte >= 128 的像素全压到 255，
实测单帧损失 **5.5%–19.7%** 像素（随画面亮度变化）。已全部重新导出。
