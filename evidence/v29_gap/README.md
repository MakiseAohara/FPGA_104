## 加速器时间证据（已有数据）

来源：`evidence/v29_gate/v291/phase_b_direction.log`（第二轮模型，n=600）与 `evidence/v29_day_scene/log_v29_day_scene.log`（旧 MobileNet 模型，n=522）。`ms` 为固件对 `Invoke()` 前后读 CLINT 的差值。

| 模型 | 参数量 | 估算乘加次数 | 单次推理（中位数 / p95 / 最大） |
|---|---|---|---|
| 第二轮自训练（5 层 Conv + GAP + 2 FC） | 95,922 | 约 6.39 M | **226 / 226 / 226 ms** |
| 旧 MobileNetV1 0.25× | — | — | 446 / 447 / 447 ms |

- 乘加次数按层核算：Conv1 0.33 M，Conv2 2.65 M，Conv3 1.99 M，Conv4 1.00 M，Conv5 0.41 M，全连接 0.003 M。
- 226 ms 对应约 28 M 乘加/s，决策循环约 1.45 Hz。这个数是**加速器参与时**的实测值。
- **不能写**"加速器比纯 CPU 快 N 倍"：我们没有纯 CPU 对照实测。如要写倍数，需要关闭加速器再跑一次同模型（改 TinyML 配置，不在本轮范围）。
- 抖动极小（最小=最大），说明推理耗时稳定，可用于决策周期估算。
