# 实际网页画面帧率基线

测试方式：真实 Edge 浏览器，PC页20秒后关闭，再测板页10秒。Canvas `drawImage` 完成一次为一次画面绘制，以图片URL中的 `seq` 去除重复快照。采集HTTP图片字节SHA256辅助确认内容变化；相同场景像素不变不直接等同重复采集。未占用COM15、重启服务、修改产品源码或下载硬件。

| 项 | PC网页 | 板内网页 |
|---|---:|---:|
| 测量时长 | 20.020s | 10.003s |
| 完成绘制 | 20 | 3 |
| 唯一快照 | 3 | 3 |
| 重复绘制 | 17（85%） | 0 |
| 窗口中新帧率 | 0.150fps | 0.300fps |
| 稳态唯一帧间隔折算 | 0.179fps | 0.269fps |
| 图片请求中位耗时 | 1.883ms | 1857.707ms |
| 图片请求P95耗时 | 2.202ms | 3650.993ms |
| 状态请求中位耗时 | 3.354ms | 38.727ms |

PC数据年龄中位4823ms、最大11224ms，20次状态请求中两次connected=false。MOT样本自身sample_ms为125–475ms，说明浏览器的新帧率受上游镜像/HTTP传图限制，不能把浏览器每秒一次轮询或摄像头60Hz直接报告为网页画面帧率。

限制：时间窗口短、现役PC镜像持续运行，板页测试期间存在共享板端HTTP连接资源；并非无其他读者的理想单客户端上限。3个唯一帧的稳态FPS统计误差较大，作为现场基线而非长期性能承诺。

复测时可运行本脚本并指定 `--out <另一个目录>`，避免覆盖基线证据。脚本当前检测HTMLImageElement的drawImage，若后续产品改为原始像素/putImageData渲染，需要同步调整采集点，不能将未捕获误报成0fps。
