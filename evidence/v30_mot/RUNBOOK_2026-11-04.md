## 1. 预测验收（4 分钟，当前固件）

```powershell
py -3 -u tools\capture_pred.py --port COM15 --out out\pred_A
```

会先响 3 声（准备），之后每一步响 1 声 + 屏幕大字。**按提示音做动作**：

| 阶段 | 时长 | 你要做的 |
|---|---|---|
| READY | 15 s | 走开，画面里没人 |
| STAND | 20 s | 站画面中间，正面朝镜头，别动 |
| APP1~5 | 各 12 s | 先退出画面 4 s → **朝镜头**走过来 → 到约 1.5 m **停 4 s** |
| LEAVE | 20 s | 走出画面 |

> 关键：是"朝镜头走"，不是左右平移；每轮从同一位置出发；速度正常走路，别冲刺。

采集完会自动打印判定（同时写 `out\pred_A\accept.json`）：

```text
[PASS] 有效接近次数 >= 3
[PASS] 每次 lead_ms > 0
[PASS] lead_ms 中位 >= 400 ms
[PASS] 空场无误报
[PASS] 站定无误报
[PASS] pre_eta 下降片段 >= 70%
总判定: PASS
```

`数据不足` = 一次预警都没触发（不是失败），先看 `out\pred_A\serial.log` 里
`MMT_MOT nd=` 有没有变 1、`MMT_ALARM start` 有没有出现。


## 常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `PermissionError(13, 'Access is denied', None, 2)` | COM15 被占 | 关掉 `web_monitor.py` / 其它串口工具窗口 |
| `ModuleNotFoundError: No module named 'serial'` | 缺 pyserial | `py -3 -m pip install pyserial` |
| 采集到 0 行 | 波特率/端口不对 | 板子固定 **115200**，端口 `COM15`（设备管理器确认） |
| `LOAD_OK` 不出现 | 位流没重配（板子不在 loader） | 先执行 3.1 再 3.2 |
