# ③ 两人并发：粘连前景切分（v1.9）

日期：2026-11-02
范围：只改 `mot_core.h`（检测层）+ `test_mot.c`，**未重建位流/固件，未上板**。

## 1. 问题

之前的已知缺陷：两个人挨在一起走时，膨胀后的前景会粘成**一个**连通域，
`mot_label()` 只上报一个检测 → 关联层只能得到 1 条航迹，于是"同时确认航迹 ≥2 的帧数 = 0"。

## 2. 做法（检测层切分）

```
mot_label():
  1) 连通域标记时把 lab[] 写成"连通域 id"（原来是 0/1，无法二次访问同一块）
  2) 每个连通域算完面积/包围盒后调用 mot_find_split()
     - 宽度 < MOT_SPLIT_MIN_W(20) 或高度 < MOT_SPLIT_MIN_H(12) → 不切
     - 面积 < 2*MOT_MIN_AREA(60) → 不切
     - 统计该连通域的**列投影**，在中间 1/3 区间找谷
       谷深 >= MOT_SPLIT_VALLEY(35%) → 认为"两个人"；否则是"一个宽目标"
     - 切分后左右各自面积 >= MOT_MIN_AREA → 才切
  3) 切开的左右两块分别走原来的"鬼影剔除 / 重复抑制 / 容量"流程，各自生成一个检测
```

新增常量（均可用 `-D` 覆盖，方便 A/B）：`MOT_SPLIT_MIN_W` / `MOT_SPLIT_MIN_H` / `MOT_SPLIT_VALLEY`。
关闭切分：`cl /DMOT_SPLIT_MIN_W=999 ...`。

## 4. 合成双人回放（真实帧合成）

素材：`evidence/v29_scene/frames` 的 329 张真实 96×96 帧 → 取时间中位数当背景，
抠出一个人形贴到两个相距 3 px 的位置（膨胀后必然粘连），同向缓慢平移 60 帧。
逐帧喂给 `replay_mot`，对比"开/关切分"：

| 指标（60 帧） | 关闭切分 | 开启切分 |
|---|---|---|
| 检测数 ≥2 的帧 | 21 | **23** |
| 同时确认航迹 ≥2 的帧 | 22 | **24** |
| 平均检测数 | 1.47 | **1.58** |
| 平均确认航迹 | 1.48 | **1.55** |

结论（如实）：**方向正确但增益有限**。合成画面里除了两个人还有背景残差和伪影，
它们本身就会产生额外检测，掩盖了切分的效果；真实双人场景（两人并肩、部分遮挡）
必须在板上用两个人实测才算数。


## 4b. 离线验证第二轮（更干净的数据 + 宽高比约束）

第一轮的合成数据有问题：两人间隔只有 2 px，3×3 膨胀会把缝隙完全糊住 → 列投影没有谷，
切分当然不触发。重做时把间隔放到 6 px、只用中段 6×6 的"桥"把两块连起来，
并新增两条**宽高比**约束：

| 常量 | 值 | 作用 |
|---|---|---|
| `MOT_SPLIT_MIN_ASPECT` | 70 | 宽/高 < 0.70 → 不像两个人（单人约 0.30~0.40），不切 |
| `MOT_SPLIT_MAX_ASPECT` | 170 | 宽/高 > 1.70 → 像背景墙条而不是并肩两人，不切 |

每个场景 45 帧，`replay_mot` 跑两遍（`-DMOT_SPLIT_MIN_W=999` 关闭 / 默认开启）：

| 场景 | 指标 | 关闭切分 | 开启切分 | 差异 |
|---|---|---|---|---|
| apart2（两人间隔 12 px） | 检测/帧、确认/帧 | 2.47 / 2.38 | 2.47 / 2.38 | **0** |
| **bridge2（间隔 6 px + 中段窄桥）** | 检测/帧、确认/帧 | 2.04 / 1.96 | **2.42 / 2.29** | **+0.38 / +0.33** |
| overlap2（重叠 4 px，本应算 1 人） | 检测/帧、确认/帧 | 1.73 / 1.73 | 1.73 / 1.73 | **0** |
| one2（单人） | 检测/帧、确认/帧 | 1.53 / 1.53 | 1.53 / 1.53 | **0** |
| real（真实单人序列 329 帧） | 检测/帧、确认/帧 | 1.27 / 1.26 | 1.24 / 1.20 | −0.03 / −0.06 |
| real（同上） | "确认≥2"的帧数 | 66 | **72** | **+6（≈1.8%）** |

### 结论（如实）

1. **只在"窄桥粘连"这个目标场景生效**：检测/帧 +0.38、确认/帧 +0.33；
   其余三个合成场景（分开、完全重叠、单人）开关前后**逐帧完全一致**，没有误切。
2. **真实单人序列上有约 1.8% 的帧会多出一次"误切"**（conf≥2 的帧 66→72），
   说明宽高比约束还不够严——真实画面里的宽背景块偶尔仍满足 0.7~1.7 的宽高比。
3. 因此**默认不建议打开**：本特性用 `-DMOT_SPLIT_MIN_W=999` 即可完全关闭，
   出货固件（v30s `E6535D37`）未包含这版 mot_core，无回归风险。
   等真实双人素材（两人并肩走、部分遮挡）到手，再用同样方法调 `MOT_SPLIT_VALLEY` 与两条宽高比阈值。
