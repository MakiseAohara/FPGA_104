# 跟踪与预测算法变更（离线）

本轮只修改隔离副本，不烧录板卡、不改现役网页。核心为自写纯 C，无外部项目代码。

## 确定缺陷与修复

- 框 IoU 统一使用两个包围框的面积，分母是并集。原 `mot_iou` 混用了前景像素面积，原 `mot_iou4` 把交集抵消；相同框原本只能得到 500。
- 两目标、最多六检测时穷举最多 49 个候选分配，以有效匹配数优先、总几何/外观代价次之；不再逐个抢占局部最大 IoU。
- 已确认的独立轨迹不再仅因质心靠近而合并。新生的未确认重复框仍可按很高重合度去重；相邻但不重叠的两框不再被人数统计无条件合并。
- 保存最后实际观测中心与经过时间，遮挡恢复速度按两次实际观测计算，避免把外推坐标当作新测量。
- `mot_step_timed` 使用捕获时间；重复或倒退时戳不推进状态，超过五秒的不连续重建背景/轨迹段。原 `mot_step` 保持 200ms 名义步的调用接口。
- 关联、网页预测、ROI ETA 共用 `mot_predict_position_ms`，不再关联用半速而网页用全速。速度 `vx/vy` 为 Q4 像素/200ms，默认预测前视 400ms。
- 修正 Win32/RV32 下 signed long 与 unsigned elapsed/ms 混算导致左/上运动溢出成大正速度的问题，相关乘除显式使用有符号 int64。
- 背景模型保留 Q8 小数，微小正负变化对称收敛；有 AI 或红外支撑的前景不学习进背景，以防人体拖尾拖偏质心。无支撑静态变化仍采用慢速更新。
- 连通域标签改为 16 位，避免第 256 个标签回到 0、邻接像素反复入栈而死循环。
- 单个合并观测覆盖两条已确认轨的预测中心时，不把合并框中心当任一人的实际位置；两条轨迹以 `occluded` 标记最多保留四秒。分开后全局匹配恢复 ID，外推中不计作实际观察到的人数，不用外推触发预警。

## API 与内存

`MOT_HAS_TIMED_API=1`，`MOT_HAS_GROUP_OCCLUSION=1`，`MOT_TIME_STEP_MS=200`。

`mot_step_timed(ctx, work, pixels96x96, ai_score, ir_count, timestamp_ms)`。

`mot_predict_position_ms(track, horizon_ms, &x, &y)` 返回模型外推的坐标；可能超出画面，显示层可裁切绘图，但不可声称那是实际观测位置。

MSVC 本轮 `sizeof(mot_ctx_t)=37272`，`sizeof(mot_work_t)=55296`；相对旧版增加约 27KiB，都是上下文/工作区，不引入动态分配。移植到固件需重新编译结构布局，不能只替换二进制数据结构。

## 验证

- 新增 19 项独立缺陷回归全部通过：正确 IoU、全局分配、独立双人、外观门控、正/负方向与不规则时差、遮挡速度、统一预测、ROI ETA、合并恢复、四秒期限、重复/倒退/长间断时戳、对称背景、256 连通域终止。
- 原 `test_mot.c` 20 项原封通过，未降低旧断言。
- 合成真值场景结果见 `metrics.json`。修复前后的中间退化保存在 `alg_metrics_signed_only.json` 和 `alg_metrics_bg_freeze.json`，没有删除失败实验。
- 最终合成场景：并行观测召回 0.9716，交会 0.8523，短遮挡 0.9882，停止折返 0.9886，不均匀采样 0.9886；交会与遮挡 ID 切换均为 0。400ms 预测 MAE 分别约 0.677/0.411/0.613/0.365/0.428 像素。这里只适用于明确合成矩形真值，不能作为实际人体精度。

## 边界

最多两条轨迹。基于背景差分与全局 AI/红外证据，不能替代逐人体检测器；真实多人贴身遮挡不可直接观察时，只保留有界预测。外观变化、光照、背景运动和摄像机移动仍可能导致误检或断轨。

已录制素材没有人工逐人框/ID 真值；部分帧只有稀疏抽帧/低分占位，不能据此报告真人召回率或400ms预测误差。录制代理指标有增有减，须连同输出覆盖下降一并公开，不能只报合成改善。本轮没有重新进行现场实测。
