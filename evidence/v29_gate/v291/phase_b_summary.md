# b 段（分数方向）记录

- 位流 MERGE16，固件 `tinyml_pdti8_v291_day.bin`（CRC32 `AE5896F2`，WB 固定 344/280/368，`IR_SOLO_ON=1`）。
- 采集：COM15 原始串口 299.2 s（`phase_b_direction.log`），空场→入画→离开→再入画，由人按提示执行。

## 结果：方向正确

| 分组 | n | p 中位数 | p10 | p90 | min | max |
|---|---:|---:|---:|---:|---:|---:|
| `person=1`（AI 投票判为有人） | 572 | **+104** | +14 | +126 | −113 | +127 |
| `person=0` | 28 | **−76** | −96 | +75 | −101 | +90 |

- 600 次推理里 555 次 p>0；空场尾部连续出现 −113 / −79。
- 与模型离线指标（有人中位 +101 / 无人 −105）同号同量级，**没有出现方向反转**。

## 报警

只有一次起始，没有解除：

```
MMT_ALARM start ms=4501115 f=7426 person=1 motion=1 area=881 cause=fusion
```

之后 260 s 一直是 `alarm_req=1`，直到采集结束（最后 `person=0` 也没解除）。

**原因（现场确认）**：背景里一直有人。摄像头的视野覆盖书桌/房间，背景中的人让 AI 持续判为有人
（`person=1`，p≈+100），同时 IR 也持续有热点（`irhot` 频繁为 1，`ir_cnt` 6–10）。
解除要 `infer_ran && g_person_off && ir_cnt15==0`，两个条件都因为背景人而长期不成立，
所以报警一直保持——这是场景里有人的正常结果，不是固件卡死。
数据佐证：t=130–150 s 时 `motion=0` 但 `person=1`、`ir_cnt=6–10`，即"静止的暖体仍在画面里"。

- 这不是方向问题，但会影响 c 段（20 分钟自由走动）的观感：只要 IR 有热点，报警基本不会自己解除。
- 是否要放宽解除条件（例如 `ir_cnt15==0` → `ir_cnt10 < IR_NEED`，或加超时）需要 Claude 判断，我没有改。
